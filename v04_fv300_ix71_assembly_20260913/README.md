# FV300＋IX71 主體：第一輪整機粗模

## 交付
- FV300_IX71_round1.blend：Blender 4.5.3 可編輯模型，155 個命名分件，含 65 個由 v0.3 重用的物件。
- review.html：原廠配置對照、三張實拍近似角度對照、正側俯視和推估項目。
- parts.csv：分件、來源和不確定性。
- parameters.json / build_assembly.py：整機的尺寸基準與掃描頭估值，以及建模腳本。
- inspection.json / inspect_assembly.py：從 .blend 重新載入的檢查紀錄／腳本。
- gui_check.png：實際開啟整機 Blender 視窗的截圖。
- references/：本輪下載的原廠型錄及核對用圖片；完整 PDF 與整頁圖片留作本機快取；repo 保留核對用裁圖與來源連結。

本轮僅包含 FV300、側接筒、IX71 機身、目鏡、載物台、物鏡座／可見物鏡、照明柱／聚光鏡。
不包含光學桌、外部支架、雷射電源、電腦、動畫或互動網頁。

## 在 Blender 編輯
預設 View Layer 為 01_Closed_assembly；切換到 02_Open_scanhead 可隱藏獨立的掃描頭上蓋。
按功能分 Collection。FV300_ASSEMBLY_ROOT_EST 是掃描頭父物件；選它可以移動掃描頭本體。側接筒獨立，移動後需同步調整。
每件物件的 certainty/evidence 或來源模型的 uncertainty 有推估資訊。
三張 IX71 實拍已打包在 90_References；個別參考圖預設隱藏。

掃描頭寬度、殼深、位置可在 parameters.json 調整後重建。
重建會覆寫本輪資料夾內的模型與圖表，不會更動 v0.3；若要保留本輪，先複製為新的同層資料夾。
已在 Blender 手動修改的幾何不會自動回寫至建模腳本。

## 已核對
- 你的銘牌照片顯示 IX71FVSF-2；FV300 原廠型錄列 IX71FVSF 側接口配置。
- 掃描頭在顯微鏡左側，接筒水平連接。第二個較低的相機接筒依正面實拍保留獨立外形。
- 目鏡在前、物鏡在載物台下方，聚光鏡及光纖照明頭在上方。
- 光纖頭外形參照 153221，未套用標準 IX71 的大型後接鹵素燈箱。
- 掃描頭沿用 v0.3 內構平面布局並等比例縮放，保留中央折板與右側垂直調整桿。
- 腳底位於 Z=0；台面和物鏡軸位於 (X,Y)=(0,0)，物鏡上端在台面下 3 mm，且位於中央開口範圍。這是展示間隙，不是光學工作距離規格。

## 仍有差異與推估
- 整機是一輪粗模，殼面、輪廓曲線、平台附件、聚光鏡轉盤、目鏡座與調整旋鈕仍較簡化。
- 主體上方 667 mm 高度參照的是標準配置；你的光纖配置尚未量測。
- 掃描頭外框尺寸和接筒長度／高度未實測。內構被整體抬到上緣附近，底部隱藏支撐未重建。
- 對照圖採近似相機角度，不是透視校準。三張原始照片為不同局部視野，未用單一相機硬套。
- 只建照片可見的一支工作物鏡；其餘孔位以空座表示，不推定實際裝了幾支。
- 載物台型號、照明柱背面、底部固定方式與電纜端點未知；沒有補出光路。
- 對照頁的原廠整機照是配置參考，不是你這台的照片，配件可能不同。

## 缺少的主要資料
完整整機的正面、側面與背面照；掃描頭外框長度或外框高度的量測值。
這些目前以估值處理。待整體比例確認後，再決定是否需要補拍。
