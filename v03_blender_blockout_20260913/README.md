- 全部 Z 高度、壁厚、底板與隱藏支撐均為推估，每件物件 Custom Properties 的 height_status/uncertainty 有記錄。

- 線束仅保留可見走向的簡化曲線；隱藏端點未補接。部分支撐與裝配接觸未重建。

## 缺少的視角
- 掃描頭正側面／端面：確認外框深度、橋板和輪軸高度。
